# draven
E-commerce platform for DRAVEN. Features a curated collection of gothic apparel with a focus on Victorian and modern alternative styles.
# 🖤 DRAVEN

Dress like the night. Live like the dark.

DRAVEN is a gothic clothing e-commerce website built for the modern alternative fashion lover. From Victorian lace to cyber-goth edge, DRAVEN curates dark aesthetic apparel for those who find beauty in the shadows.

---

 About the Project

This repository contains the source code for the official DRAVEN online storefront. The site is designed to deliver a moody, elegant shopping experience that matches the brand's dark aesthetic — because goth fashion deserves a goth website.
